# 肝癌研究周报 (HCC Weekly)

每周自动更新的肝癌领域研究动态周报，覆盖 **原发性肝癌全域**（肝细胞癌与肝内胆管癌为主，其他肿瘤肝转移为重点亚方向）。

**在线阅读**：https://fengtingting0319-beep.github.io/HCC-weekly/ （从总目录进入各期）

## 数据源与口径

| 数据源 | 口径 |
|---|---|
| PubMed (E-utilities) | EDAT 窗口限定（检索窗口内新增收录），英语文献 |
| bioRxiv / medRxiv | API 按日期窗口拉取 + 肝癌关键词过滤，预印本不参与分级 |
| ClinicalTrials.gov (API v2) | LastUpdatePostDate 窗口限定 |
| 指南与共识 | PubMed 指南/共识类型限定（累计口径，best-effort） |

## 周报内容

- **本期概览 / 数据面板**：检索漏斗、S/A/B/C 证据分级、影响因子核实
- **Top10 精读**：五维评分（设计 30 / 验证 15 / 机制 15 / 影响力 20 / 契合度 20）
- **全部文献**：按周分组，支持等级/主题/类型筛选与多维排序
- **预印本区 / 临床试验动态 / 指南与共识**
- **本周热点与趋势总结** / **方法与检索式**（可复制复现）

## 运行方式

- GitHub Actions 每周一 09:00（北京时间）自动运行：抓取 → 清洗分级 → 渲染 → 发布
- 手动触发：Actions → weekly-update → Run workflow

## 标注说明

- 中文标题、要点启示、精读与热点述评由大模型辅助生成，仅供参考，请以原文为准
- 影响因子为 JCR 2024 静态对照表（best-effort，可能滞后）
- 自动流水线对新增文献采用规则评分回退；AI 精读标注层见 `pipeline/annotations.py`
